- transportation preferences

"flexible morning options",

"if time permits",

- day number
- short day theme
- exact date

For each activity include:
- start time
- activity name
- category
- duration
- useful address or area
- one short description

End each day with:
- number of stops
- approximate active time
- main transportation method

Keep it TL;DR:

- keep each field on its own line
